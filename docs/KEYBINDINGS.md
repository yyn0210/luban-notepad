# 键盘快捷键

GPUI 使用平台的次级修饰键：Linux/Windows 上为 **Ctrl**，macOS 上为 **Cmd**。
为简洁起见，表格中写作 `Ctrl`。

## 扩展与片段

插件可以在 `plugin.json` 中声明命令的默认快捷键；这些绑定和内置命令一样出现在
快捷键编辑器、命令面板和快捷键帮助中，也可以被用户覆盖。插件管理器打开后焦点
位于安装输入框，`Escape` 关闭管理器。片段会话期间 `Tab` 和 `Shift+Tab` 在
占位符之间移动，`Escape` 结束会话。

## 自定义快捷键

“帮助 → 键盘快捷键 → 自定义…”打开快捷键编辑器。选择一个命令的“修改”，
然后按下新快捷键即可；`Esc` 取消本次录入。绑定会保存到
`settings.json` 的 `keybindings`，旧默认快捷键随即失效。格式无效或与另一命令
冲突时不会保存，并显示冲突的命令 ID；“默认”恢复单条，“全部恢复默认”清空
所有覆盖。命令面板（`Ctrl+Shift+P`）和快捷键帮助始终显示当前有效绑定。

## 说明

- `Ctrl+Tab` 会在编辑器收到之前被应用截获。
- 编辑类快捷键（撤销、剪切/复制/粘贴、全选、缩进等）只在编辑器拥有焦点时
  由命令层处理；查找框和对话框保留自己的文本编辑快捷键。
- `Ctrl+F`/`Ctrl+H` 在应用层处理；编辑器内置的查找面板已被禁用，
  因此只有一个查找界面。
- 针对编辑器的菜单操作（撤销、剪切、粘贴、缩进）会先把焦点还给编辑器，
  再分派编辑器动作，因此行为与键盘快捷键一致。
