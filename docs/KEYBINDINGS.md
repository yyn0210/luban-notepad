# 键盘快捷键

GPUI 使用平台的次级修饰键：Linux/Windows 上为 **Ctrl**，macOS 上为 **Cmd**。
为简洁起见，表格中写作 `Ctrl`。

## 应用

| 操作 | 快捷键 |
| --- | --- |
| 新建文档 | `Ctrl+N` |
| 打开文件 | `Ctrl+O` |
| 打开文件夹 | `Ctrl+Shift+O` |
| 保存 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |
| 关闭标签页 | `Ctrl+W` |
| 关闭所有标签页 | `Ctrl+Shift+W` |
| 查找 | `Ctrl+F` |
| 替换 | `Ctrl+H` |
| 查找下一个 | `F3` |
| 查找上一个 | `Shift+F3` |
| 在文件中查找 | `Ctrl+Shift+F` |
| 跳转到行 | `Ctrl+G` |
| 复制行 | `Ctrl+D` |
| 删除行 | `Ctrl+Shift+K` |
| 切换行注释 | `Ctrl+/` |
| 放大 | `Ctrl++` 或 `Ctrl+=` |
| 缩小 | `Ctrl+-` |
| 重置缩放 | `Ctrl+0` |
| 下一个标签页 | `Ctrl+Tab` 或 `Ctrl+PageDown` |
| 上一个标签页 | `Ctrl+Shift+Tab` 或 `Ctrl+PageUp` |
| 激活标签页 1–9 | `Ctrl+1` … `Ctrl+9` |
| 退出 | `Ctrl+Q` |
| 关闭浮层 / 取消 | `Escape` |
| 确认查找、替换、跳转到行、文件对话框 | `Enter` |

## 编辑器

以下快捷键由 GPUI Base 的编辑器提供：

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Shift+Z` |
| 全选 | `Ctrl+A` |
| 剪切 / 复制 / 粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` |
| 按词移动 | `Ctrl+Left` / `Ctrl+Right` |
| 按词选择 | `Ctrl+Shift+Left` / `Ctrl+Shift+Right` |
| 行首 / 行尾 | `Home` / `End` |
| 文档开头 / 结尾 | `Ctrl+Home` / `Ctrl+End` |
| 向上 / 向下翻页 | `PageUp` / `PageDown` |
| 增加 / 减少选区缩进 | `Tab` / `Shift+Tab` |
| 自动缩进换行 | `Enter` |
| 自动闭合括号/引号 | 输入 `(`、`[`、`{`、`"`、`'` |

## 菜单

| 菜单 | 内容 |
| --- | --- |
| 文件 | 新建、打开、打开文件夹、最近文件、保存、另存为、全部保存、重新加载、关闭、全部关闭、退出 |
| 编辑 | 撤销/重做、剪切/复制/粘贴/全选、增加/减少缩进、复制/删除行、切换注释、去除空白、大小写转换、排序行、换行符转换、编码选择 |
| 搜索 | 查找、替换、查找下一个/上一个、跳转到行、在文件中查找、清除高亮 |
| 视图 | 自动换行、行号、工具栏/状态栏/浏览器显隐、缩放、浅色/深色主题、语言选择器 |
| 设置 | 首选项 |
| 帮助 | 键盘快捷键、关于 |

## 说明

- `Ctrl+Tab` 会在编辑器收到之前被应用截获。
- `Ctrl+F`/`Ctrl+H` 在应用层处理；编辑器内置的查找面板已被禁用，
  因此只有一个查找界面。
- 针对编辑器的菜单操作（撤销、剪切、粘贴、缩进）会先把焦点还给编辑器，
  再分派编辑器动作，因此行为与键盘快捷键一致。
