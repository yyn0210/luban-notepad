# 文件选择器重构设计

- 状态：已确认，实施中
- 范围：打开文件、另存为、选择文件夹、打开/保存工作区、导入/导出设置与主题、查找文件夹
- 原则：保留自绘对话框与跨平台一致外观，不切换系统原生对话框

## 1. 目标

把现有内置文件对话框升级为编辑器里最好用的文件选择器：

- 导航快：常用位置侧栏、面包屑、可编辑地址、前进/后退/上一级、最近目录。
- 查找快：当前目录即时搜索、通配符、类型筛选、可排序列、type-ahead。
- 信息足：名称/大小/修改时间、选中汇总、文本内容预览、编码/EOL/语言。
- 操作稳：单击选择/双击进入、多选、新建文件夹、右键菜单、行内错误与重试。
- 键盘优先：方向键、Home/End/PageUp/PageDown、Enter、Space、Ctrl+A/F/L/H、F5、Alt+方向键。
- 性能稳：后台列举、虚拟化列表、预览防抖与缓存，大目录不阻塞 UI。

## 2. 布局

弹层宽度 `clamp(760, 窗口宽 - 48, 1120)`，高度 `clamp(480, 窗口高 - 96, 720)`；
宽度不足 980 时自动收起预览。

三种模式共用骨架：

- 打开：底部无文件名输入，确认按钮「打开」。
- 另存为：底部常驻文件名输入，确认按钮「保存」。
- 选择文件夹：底部提示当前/高亮文件夹，确认按钮「选择文件夹」。

## 3. 交互规则

### 3.1 点击

- 单击文件：单选并设为当前行；Ctrl/Cmd+点击切换；Shift+点击范围选择。
- 单击目录：只设为当前行并清除文件选择，不进入。
- 双击文件：打开并关闭对话框；双击目录：进入。
- `..` 行是导航按钮，单击返回上一级。
- 保存模式单击文件回填文件名；文件夹模式单击目录只选中，双击进入。
- 右键：打开、复制路径、在文件管理器中显示、新建文件夹、刷新。

### 3.2 键盘

| 按键 | 行为 |
| --- | --- |
| ↑/↓/Home/End/PageUp/PageDown | 移动当前行 |
| Enter | 文件/多选打开；打开/保存模式目录进入；文件夹模式确认当前或高亮目录 |
| Space | 切换当前文件选中 |
| Ctrl/Cmd+A | 全选可见文件 |
| Ctrl/Cmd+F | 聚焦搜索 |
| Ctrl/Cmd+L | 地址栏编辑 |
| Ctrl/Cmd+H | 显示/隐藏隐藏文件 |
| Alt+← / Alt+→ | 后退 / 前进 |
| Alt+↑ / Backspace | 上一级 |
| F5 | 刷新并保留选择 |
| Esc | 先退出地址/清空搜索/取消新建，再关闭对话框 |

列表拥有独立焦点；点击行、侧栏、面包屑后焦点回到列表。弹层打开期间拦截全局快捷键。

### 3.3 搜索与筛选

- 搜索只过滤当前文件夹，不递归。
- 纯文本按大小写不敏感子串匹配；含 `*`/`?` 按通配符匹配；匹配片段高亮。
- Enter 打开当前行/唯一匹配。
- 类型筛选下拉：所有文件、文本文件、按用途的扩展名预设、自定义模式。
- 自定义模式支持 `*.md; *.txt`，空模式视为所有文件。
- 另存为在文本筛选下自动补 `.txt`；扩展名筛选下自动补对应扩展名。

### 3.4 导航

- 每个对话框独立历史栈（上限 50）；前进/后退/上一级按钮按可用性置灰。
- 面包屑超过 5 段时中间折叠为 `…` 菜单；Ctrl+L 或「路径」按钮切换为地址输入。
- 地址支持 `~`、相对路径（相对当前目录）和完整路径。
- 地址输入文件路径时跳到父目录并选中该文件，不直接打开。
- 最近访问目录写入 `settings.json` 的 `recent_dirs`（上限 12，侧栏展示 5）。

### 3.5 排序

- 点击名称/大小/修改时间列头切换升降序。
- 目录始终排在文件前；目录内部按名称；文件按所选列。
- 名称使用自然排序（`file2` 在 `file10` 前）。

### 3.6 新建文件夹

- 工具栏按钮或右键菜单触发；列表顶部显示内联输入行。
- 使用 `file_ops::validate_name/create_dir`；创建后进入新目录。
- 错误行内显示，不关闭对话框。

## 4. 预览

- 选中单个文件时后台读取前 64 KiB；100ms 防抖；8 项缓存。
- 二进制、超大、无权限分别降级提示。
- 文本最多展示 200 行（行号、等宽字体、Tab 展开为 4 空格），可滚动。
- 显示大小、修改时间、语言、编码、EOL；多选显示数量与合计大小；目录显示文件夹信息。

## 5. 模块结构

```
crates/luban-app/src/
  file_picker/
    mod.rs        // FileDialogState、模式/用途、选择、历史、排序/筛选规格、面包屑
    places.rs     // 常用位置、最近目录、磁盘/挂载点枚举
    listing.rs    // PickerEntry、自然排序、搜索、格式化
    preview.rs    // 预览采样、解码、截断、缓存
  app/
    file_picker_ui/
      mod.rs      // 入口动作、确认/取消、异步编排、整体 frame
      chrome.rs   // 标题、导航、面包屑/地址、搜索/筛选/新建文件夹
      list.rs     // 表头、虚拟化行、状态区
      sidebar.rs  // 常用位置
      preview.rs  // 预览面板
```

- `dialogs.rs` 只保留确认框、跳转行、语言选择等通用弹层。
- `FileDialogPurpose`、`SaveThen`、`SaveAsRequest` 语义不变，调用方行为不变。
- 目录列举新增 `luban_core::workspace::list_directory_detailed`，带大小/修改时间/符号链接信息；现有 `list_directory` 复用它并保持原返回值。
- 列表使用 GPUI `uniform_list` 虚拟化，只渲染可见行。
- 每次列举/筛选/排序变化只重算一次 `Arc<Vec<PickerRow>>` 快照。
- 目录列举与预览都带 generation，过期结果丢弃。

## 6. 持久化与兼容

- `Settings` 新增 `recent_dirs`（`#[serde(default)]`），旧配置不受影响；关闭对话框时统一写入。
- 不新增第三方依赖：时间格式化使用已在依赖树中的 `chrono`；磁盘枚举使用 `std` + 已有平台依赖。
- Linux `/proc/mounts` 解析、macOS `/Volumes`、Windows `GetLogicalDrives`。
- 新增 i18n key 同时提供 en / zh-CN；沿用现有主题 token。

## 7. 验证

- 单测：搜索/通配符、筛选与默认扩展名、自然排序、目录优先、选择语义、历史、路径展开、挂载解析、预览截断/二进制、按用途默认筛选。
- UI：Xvfb + xdotool 验证导航、搜索、多选、新建文件夹、保存模式、预览、窄窗口收起；亮/暗主题截图检查。
- CI：`cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace`。

## 8. 非目标

- 不做递归全文搜索（使用 Find in Files）。
- 不做收藏夹、编码选择下拉、云盘/最近文件集成。
- 不切换系统原生对话框，不引入新的 UI 依赖。
