# 与 Notepad++ 的功能对照

图例：**是** = 已实现并经过验证；**部分** = 实现了可用的子集；**否** = 本版本未实现。

## 文件与会话

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 新建 / 打开 / 保存 / 另存为 | 是 | 内置跨平台文件对话框；支持路径输入、多选打开、文件类型过滤、键盘导航和后台目录列举。 |
| 全部保存 / 关闭 / 全部关闭 | 是 | 未保存的更改会受保护。 |
| 从磁盘重新加载 | 是 | 手动操作；重新读取标签页并清空撤销历史。 |
| 最近文件 | 是 | 保存在 `settings.json` 中；显示在“文件”菜单里。 |
| 大文件打开（≥100 MB） | 是 | 后台读取/解码，窗口保持可交互；自动进入大文件模式。 |
| 大文件编辑与保存 | 是 | 保留编辑、撤销/重做、保存、另存为；关闭高亮、自动换行、括号匹配和实时查找高亮。 |
| 大文件控制器（≥200 MB） | 是 | 自动显示右侧面板；支持整个/开头/结尾/中间范围、从/到/大小滑杆、进度、停止、单位切换和可用磁盘空间。超过 `max_file_size_mb` 的文本文件默认以磁盘引擎打开整个文件；非文本文件仍默认只加载开头 200 MiB。 |
| 超大文件磁盘引擎（> `max_file_size_mb`，默认 1 GiB） | 是 | 后台建立约 1 MiB 的块索引，编辑器只挂载光标附近的 2 MiB 窗口；可编辑、跨窗口滚动/跳转、跨窗撤销/重做、全文查找替换，并按普通 Ctrl+S 语义原子保存。未修改内容保持原始字节，打开时不做整文件临时副本。标签页显示文件全局行号栏，宽度随总行数增长。 |
| 磁盘引擎编码与换行符 | 是 | UTF-8/BOM、UTF-16 LE/BE（含无 BOM）、Windows-1252 以及 LF/CRLF/CR；保存时保留编码、BOM 有无、换行符风格和未修改区域字节。 |
| 磁盘引擎保存/另存为/重新加载/关闭 | 是 | 后台流式写同目录临时文件，`fsync` 后原子替换；保存期间显示进度并可停止；外部修改需确认覆盖或重新加载；另存为切换标签页路径；重新加载前确认丢弃修改；关闭/退出参与未保存提示与全部保存；保存成功后删除对应恢复数据。 |
| 磁盘引擎跨窗口选择/块操作 | 否 | 窗口化模型的限制：选择、复制和编辑限于当前窗口，不能跨窗口建立选区或整篇打印。 |
| 磁盘引擎崩溃恢复 | 是 | 未保存编辑以 checkpoint + 追加操作日志写入配置目录的 `recovery/`；崩溃或强制退出后下次启动提示恢复内容、光标和滚动位置；源文件已变化或缺失时拒绝自动重放；保存、关闭或放弃后删除恢复数据，30 天后清理过期数据。 |
| 部分打开与保存 | 是 | 片段可编辑、撤销/重做和查找；只能另存为新文件，绝不写回源文件；会话按区间恢复。超过上限的文本文件默认走磁盘引擎，而不是部分打开。 |
| 大文件行筛选 / 临时文件编辑 | 否 | 控制器本轮只做范围控制；EmEditor 的筛选、临时文件和自定义入口未实现。 |
| 会话恢复 | 是 | 标签页、活动标签页、光标/选区、工作区、窗口大小、未保存缓冲区。大文件不保存缓冲区，重启后从磁盘读取；部分打开的区间会保留；磁盘引擎标签页额外记录恢复标识。 |
| 会话自动保存 | 是 | 间隔可在 `settings.json` 中配置（默认 20 秒）。 |
| 命令行文件参数 | 是 | 支持多个文件。 |
| 外部变更监视 | 是 | 监视每个打开文件的父目录并防抖；外部修改、删除或重命名时显示非模态横幅，可重新加载或保留；忽略应用自身保存产生的事件。监视不可用时保存前检查仍然生效。 |
| 将文件拖放到窗口 | 部分 | Linux 与 Windows 下从桌面拖入一个或多个文件即直接打开；已打开的文件只激活现有标签页。目录不会被当作工作区打开。macOS 受 GPUI 后端限制暂未接入。 |
| 打开对话框中多选文件 | 是 | Ctrl/Cmd+点击、Shift+点击或 Ctrl/Cmd+A 多选；确认后逐个打开，已打开的文件只激活现有标签页。 |
| 打开对话框双击打开 | 是 | 双击文件名立即打开该文件并关闭对话框；双击只打开被双击的文件，不受此前多选影响。 |
| 文件类型过滤 | 是 | 打开/另存为对话框可切换“所有文件/文本文件”；文本过滤器下另存为自动补 `.txt`。 |
| 文件对话框键盘与无障碍 | 是 | 方向键/Home/End/PageUp/PageDown 导航，空格切换选中，Enter 确认；列表暴露 ListBox 语义。 |
| 本地历史 | 是 | 普通文本文件保存前把旧磁盘内容快照到配置目录 `history/`；按文件和保存前版本浏览、恢复为未保存缓冲区、清空；同名内容去重；按保留天数（默认 30 天）和每文件空间上限（默认 200 MB）清理。磁盘引擎、部分范围、非文本和无标题文档不生成快照。 |
| 文件日志与崩溃诊断 | 是 | `logs/luban.log` 记录带时间、级别和目标的日志，超过 5 MiB 轮转并保留 3 份；panic hook 向 `logs/crash.log` 追加消息、位置和回溯；帮助菜单可打开日志目录。日志目录不可写时降级到终端，不影响启动。 |
| 导出 HTML / RTF | 是 | 当前文档带语法颜色导出为独立文件，通过保存对话框选择路径。 |
| 打印 | 否 | |
| 文档备份/原子保存 | 是 | 普通文档与磁盘引擎文档都在目标目录写唯一临时文件，`flush` + `fsync` 后原子替换，保留原文件权限并跟随符号链接；失败时删除临时文件、保留原文件并报告错误，不回退为直接覆盖写；会话采用原子写入。 |

## 工作区、导航与多窗口（0.16）

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 文件树操作 | 是 | 多根树；新建文件/文件夹、重命名、删除（默认回收站；失败后可确认永久删除）、刷新、复制路径、在文件管理器中显示；新建文件自动打开；重命名同步更新已打开标签页、最近文件和外部监视。 |
| 工作区文件 | 是 | `.luban-workspace` JSON：`version`/`name`/`roots`/`settings`；相对根按文件目录解析；未知版本降级为默认覆盖；最近工作区最多 20 条；支持打开、保存、另存为、添加/移除根和关闭。 |
| 工作区设置覆盖 | 是 | 缩进宽度、空格/制表符、自动换行、行号、空白字符、缩进参考线、标尺及列、文档地图、`.gitignore`、搜索 include/exclude；未出现字段继承全局；主题、字体、快捷键、宏、每语言设置和本地历史保持全局。 |
| `.gitignore` 感知索引 | 是 | 后台索引所有根，遵守嵌套 `.gitignore`、`.git/info/exclude` 和全局 gitignore，跳过 `.git`；隐藏文件跟随设置；单根上限 200,000 个文件并在状态栏/快速打开提示截断。 |
| 快速打开 / Goto Anything | 是 | `Ctrl+P` 子序列模糊匹配工作区相对路径；打开中的文件优先，最多 50 条；`:123` 跳转活动文档行；`@name` 搜索当前大纲符号；`file:42` 先打开文件再跳转。 |
| 符号大纲 | 是 | 文件树下方面板；正则启发式覆盖 Rust、Python、JS/TS、C/C++、Java/C#/Kotlin、Go、Ruby、PHP、Shell、Markdown；按缩进分层、可折叠、点击跳转，上限 5,000；大文件/磁盘引擎/部分范围/非文本显示不可用。 |
| 面包屑 | 是 | 工作区/根 → 相对目录 → 文件名 → 当前符号；目录和文件名段打开快速打开并填入前缀，符号段跳转；未命名和大文件模式省略符号；可隐藏并持久化。 |
| 导航历史 | 是 | 每窗口独立的前进/后退（`Alt+←/→`），记录标签、光标、选区和滚动；上限 100；已关闭标签自动跳过；无历史时命令禁用。 |
| 多窗口 | 是 | `Ctrl+Shift+N` 新窗口；标签可移动到新窗口并保留文本、编码、换行、光标、书签、部分范围和磁盘引擎恢复；关闭窗口只影响自己的标签，最后一个窗口退出应用。 |
| 多窗口会话 | 是 | 会话升级为 v2，保存所有窗口的位置/大小/最大化、工作区文件/根、分屏、活动组和每组标签；v1 自动迁移为单窗口；离屏位置改为居中，尺寸夹取到至少 480×320。 |
| 分屏与标签组 | 是 | 向右/向下分屏、取消分屏；最多两个编辑组，每组独立标签栏/活动标签/编辑器；标签可拖拽或通过命令/右键菜单移组；布局和活动标签随会话恢复。 |
| 全库搜索 | 是 | 工作区范围、include/exclude glob（`*`、`?`、`**`）、`.gitignore` 开关、可取消后台搜索、按文件分组结果；默认展开第一个文件和前 20 个匹配所在文件；上限 20,000 并提示截断。 |
| 全库替换 | 是 | 预览文件数/匹配数/前 5 条样例/跳过原因；应用前重新读取并比较指纹；只修改内存缓冲区并标记未保存；磁盘引擎/部分范围/非文本/大文件标签跳过；最近一次替换可撤销，不写盘。 |
| 设置搜索 | 是 | 首选项顶部按空白分隔关键字过滤设置组，中英文标题和英文/中文关键字均可匹配；无匹配显示空状态；关闭首选项清空搜索。 |
| 设置导入/导出/重置 | 是 | 导出完整全局设置 JSON；导入先解析校验再确认，失败保持原设置；重置二次确认并清空快捷键、宏、每语言设置、最近文件和最近工作区，原子写入。 |
| 文档地图 | 是 | 右侧 90px 面板，普通文档采样最多 4,000 行绘制行宽轮廓和视口矩形；大文件/磁盘引擎/部分范围使用比例映射；点击滚动，Shift+点击同时移动光标；少于 20 行或高度不足 40px 时隐藏。 |
| 空白字符/缩进参考线/标尺 | 是 | 三个独立开关；空白字符显示空格点与制表符箭头；缩进参考线默认开启；标尺按 `ruler_columns`（默认 80/120，1–500）在未自动换行的普通文档绘制 1px 竖线。 |
| 括号配色 | 是 | 普通文本且不超过 2 MB 时按嵌套深度循环着色 `()[]{}`；未配对括号不着色；光标移动、编辑、撤销或主题切换后更新；不解析字符串/注释（已在本文和 `docs/ACCESSIBILITY.md` 记录为已知近似）。 |
| 无障碍 | 是 | 文件树、大纲、文档地图暴露语义角色和标签；树支持方向键/Enter/F2/Delete/Ctrl+N；快速打开沿用命令面板键盘导航；新增命令均有默认或可分配快捷键并出现在命令面板；详见 `docs/ACCESSIBILITY.md`。 |

## 扩展性（1.0）

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 插件清单与发现 | 是 | `config_dir()/plugins/<id>/plugin.json`；校验 ID、SemVer、`api_version`、入口文件、贡献点、权限和依赖；重复 ID、非法清单和依赖环被拒绝，单个插件失败不影响启动。 |
| 插件运行时 | 是 | 沙箱化 Lua 5.4（mlua）；只开放基础/字符串/表/数学/UTF-8 库，移除 `io`、`os`、`package`、`debug`、`require`、`load`；单回调 50,000,000 条指令上限、64 MiB 内存上限；错误被捕获并显示。 |
| 插件权限 | 是 | 清单声明 `filesystem`/`network`/`process`；本版本只实现 `filesystem`（工作区根、活动文档目录和插件数据目录）；安装/更新时展示权限并记录 SHA-256 批准哈希，权限变化后需重新批准。 |
| 插件贡献点 | 是 | 命令、插件菜单、默认快捷键、状态栏项、声明式设置（布尔/字符串/数字/枚举）和文本/列表面板；插件命令进入命令面板、快捷键帮助、快捷键编辑器和宏录制。 |
| 插件文档 API | 是 | 读取路径/全文/语言/光标/选区；替换全文、在光标处插入、替换选区；只对可编辑全文文档生效，写入可撤销并走现有保存/外部修改保护。 |
| 插件管理器 | 是 | 首选项“插件”页和“管理插件”浮层；启用/禁用、批准权限、卸载、从本地目录/zip/Git 安装、从记录源更新；安装前校验并原子替换，zip 路径穿越和逃逸符号链接被拒绝。 |
| 用户语法 | 是 | `packages/syntaxes/**.sublime-syntax` 合并到内置语法集；新语言进入语言选择器、扩展名检测和首行匹配；编辑器高亮与 HTML/RTF 导出共用同一语法集；非法文件跳过。 |
| 用户主题 | 是 | `packages/themes/**.tmTheme` 出现在语法主题列表；选择后应用到编辑器高亮和导出；损坏/缺失回退默认；旧版单个 `.tmTheme` 导入仍可用。 |
| 用户片段 | 是 | `packages/snippets/**.sublime-snippet` 和 `.json`；按语言/scope 过滤；`edit.insert-snippet`（`Ctrl+Alt+S`）打开选择器；支持 `$1`/`${1:默认}`/`$0`，Tab/Shift+Tab 导航，Esc 结束，整体撤销。 |
| 安全模式 | 是 | `--safe-mode` 或设置中关闭“启用插件”时不加载任何插件；用户语法/主题/片段仍加载。 |
| CLI 自动化 | 是 | `--goto path:line[:col]`、`--new-window`、`--wait`、`--diff left right`、`--stdin`/`-`、`--command <id>`、`--safe-mode`；无效参数退出码 2，请求失败退出码 3。 |
| 单实例转发 | 是 | 第二次启动把打开/跳转/命令/差异/stdin 请求转发给主实例；`--new-window` 由主实例创建新窗口；PID 锁 + `interprocess` 本地套接字（Unix domain socket / Windows 命名管道）；陈旧锁自动恢复；只有主实例写会话。 |
| 差异视图 | 是 | `--diff` 在后台打开行级统一差异只读标签，状态栏显示读取进度，`diff.cancel` 可取消；相同文件显示无差异；缺失文件报错；二进制/超大文件显示说明；标签不可编辑、不可保存。 |

## 命令、标签页与界面

| 功能 | 状态 | 说明 |
