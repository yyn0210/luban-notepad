# 与 Notepad++ 的功能对照

图例：**是** = 已实现并经过验证；**部分** = 实现了可用的子集；**否** = 本版本未实现。

## 文件与会话

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 新建 / 打开 / 保存 / 另存为 | 是 | 内置跨平台文件对话框；支持路径输入、多选打开、文件类型过滤、键盘导航和后台目录列举。 |
| 全部保存 / 关闭 / 全部关闭 | 是 | 未保存的更改会受保护。 |
| 从磁盘重新加载 | 是 | 手动操作；重新读取标签页并清空撤销历史。 |
| 最近文件 | 是 | 保存在 `settings.json` 中；显示在“文件”菜单里。 |
| 大文件打开（≥100 MB） | 是 | 后台读取/解码，窗口保持可交互；自动进入大文件模式。 |
| 大文件编辑与保存 | 是 | 保留编辑、撤销/重做、保存、另存为；关闭高亮、自动换行、括号匹配和实时查找高亮。 |
| 大文件控制器（≥200 MB） | 是 | 自动显示右侧面板；支持整个/开头/结尾/中间范围、从/到/大小滑杆、进度、停止、单位切换和可用磁盘空间。超过 `max_file_size_mb` 的文本文件默认以磁盘引擎打开整个文件；非文本文件仍默认只加载开头 200 MiB。 |
| 超大文件磁盘引擎（> `max_file_size_mb`，默认 1 GiB） | 是 | 后台建立约 1 MiB 的块索引，编辑器只挂载光标附近的 2 MiB 窗口；可编辑、跨窗口滚动/跳转、跨窗撤销/重做、全文查找替换，并按普通 Ctrl+S 语义原子保存。未修改内容保持原始字节，打开时不做整文件临时副本。 |
| 磁盘引擎编码与换行符 | 是 | UTF-8/BOM、UTF-16 LE/BE（含无 BOM）、Windows-1252 以及 LF/CRLF/CR；保存时保留编码、BOM 有无、换行符风格和未修改区域字节。 |
| 磁盘引擎保存/另存为/重新加载/关闭 | 是 | 后台流式写同目录临时文件，`fsync` 后原子替换；保存期间显示进度并可停止；外部修改需确认覆盖；另存为切换标签页路径；重新加载前确认丢弃修改；关闭/退出参与未保存提示与全部保存。 |
| 磁盘引擎跨窗口选择/块操作 | 否 | 窗口化模型的限制：选择、复制和编辑限于当前窗口，不能跨窗口建立选区或整篇打印。 |
| 磁盘引擎崩溃恢复 | 否 | 正常关闭会清理编辑日志；崩溃或强制退出不会恢复磁盘引擎标签页的未保存内容。 |
| 部分打开与保存 | 是 | 片段可编辑、撤销/重做和查找；只能另存为新文件，绝不写回源文件；会话按区间恢复。超过上限的文本文件默认走磁盘引擎，而不是部分打开。 |
| 大文件行筛选 / 临时文件编辑 | 否 | 控制器本轮只做范围控制；EmEditor 的筛选、临时文件和自定义入口未实现。 |
| 会话恢复 | 是 | 标签页、活动标签页、光标/选区、工作区、窗口大小、未保存缓冲区。大文件不保存缓冲区，重启后从磁盘读取；部分打开的区间会保留。 |
| 会话自动保存 | 是 | 间隔可在 `settings.json` 中配置（默认 20 秒）。 |
| 命令行文件参数 | 是 | 支持多个文件。 |
| 外部变更监视 | 否 | 请使用“从磁盘重新加载”。 |
| 将文件拖放到窗口 | 部分 | Linux 与 Windows 下从桌面拖入一个或多个文件即直接打开；已打开的文件只激活现有标签页。目录不会被当作工作区打开。macOS 受 GPUI 后端限制暂未接入。 |
| 打开对话框中多选文件 | 是 | Ctrl/Cmd+点击、Shift+点击或 Ctrl/Cmd+A 多选；确认后逐个打开，已打开的文件只激活现有标签页。 |
| 打开对话框双击打开 | 是 | 双击文件名立即打开该文件并关闭对话框；双击只打开被双击的文件，不受此前多选影响。 |
| 文件类型过滤 | 是 | 打开/另存为对话框可切换“所有文件/文本文件”；文本过滤器下另存为自动补 `.txt`。 |
| 文件对话框键盘与无障碍 | 是 | 方向键/Home/End/PageUp/PageDown 导航，空格切换选中，Enter 确认；列表暴露 ListBox 语义。 |
| 打印 | 否 | |
| 文档备份/原子保存 | 部分 | 普通文档仍直接写入；磁盘引擎文档使用同目录临时文件 + `fsync` + 原子替换；会话采用原子写入。 |

## 编码与换行符

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| UTF-8 / UTF-8 BOM | 是 | 保留 BOM。 |
| UTF-16 LE / BE | 是 | 可检测无 BOM 的文件；普通文档保存时会写入 BOM，磁盘引擎文档按原文件保留 BOM 的有无。 |
| ANSI / Windows-1252 | 是 | 菜单中标记为 “ANSI”。 |
| ISO-8859-1 | 是 | 映射到 WHATWG 单字节编解码器。 |
| GB18030 / Shift-JIS / EUC-KR / Big5 | 是 | 支持统计式检测。 |
| 统计式编码检测 | 是 | 对非 UTF-8 输入使用 `chardetng`。 |
| 非文本文件打开 | 是 | 参考 Notepad++ 直接按文本打开并可编辑；状态栏显示“非文本”标记。 |
| 非文本文件无损保存 | 是 | 使用可逆编码（UTF-8 或 Windows-1252），不转换换行符、不裁剪行尾空白；未编辑字节保持不变。 |
| 非文本文件换行符转换 | 否 | 非文本文档不支持转换换行符，避免改写原始字节。 |
| 换行符检测与转换 | 是 | LF、CRLF、CR。内部使用 LF。 |
| 混合换行符 | 是 | 报告主要约定；编辑时进行规范化。 |
| 保存时转换编码 | 是 | 选择编码后会在保存时重新编码。无法表示的字符会被报告。 |

## 搜索

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 字面量查找 | 是 | 大小写敏感、全字匹配、循环查找。 |
| 正则表达式 | 是 | Rust `regex`；正则模式下支持行锚点。 |
| `.` 匹配换行 | 是 | |
| 在选区内搜索 | 是 | 选区范围会被记录并保留，直到清除。 |
| 查找下一个 / 上一个 | 是 | F3 / Shift+F3 及面板按钮。 |
| 匹配计数与高亮 | 是 | 最多高亮 5,000 个范围；面板报告总数。大文件在显式查找后才搜索。 |
| 替换 / 全部替换 | 是 | 捕获组展开（`$1`、`${name}`）。 |
| 字面量替换转义 | 是 | `\n`、`\r`、`\t`、`\\`。 |
| 在文件中查找 | 是 | 文件夹、掩码、大小写、全字匹配、正则、取消、可点击结果。 |
| 磁盘引擎全文查找/替换 | 是 | 在后台按 4 MiB 分块流式扫描整个文件；“查找全部”最多收集 5,000 个匹配并显示可点击结果列表；全部替换分批应用，取消时回滚。查找只在按回车或点击按钮时触发。 |
| 在文件中查找进度 | 部分 | 不确定进度的“正在搜索…”；结束时显示已扫描文件数。 |
| 在所有打开的文档中搜索 | 否 | 请使用“在文件中查找”。 |

## 界面

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 自定义标题栏 | 是 | 应用自绘，显示固定的应用名称并提供窗口控制；标题栏与菜单栏合并为同一行。macOS 保留系统交通灯。Linux X11 使用服务端装饰并通过 `_MOTIF_WM_HINTS` 移除窗口管理器标题栏，由应用绘制标题栏和窗口控制，避免无合成器时出现黑色阴影边距；Wayland 请求客户端装饰。只有平台实际只提供服务端装饰时才使用独立菜单行。 |
| 窗口边框与缩放 | 是 | Linux X11 手动装饰窗口显示 1px 主题边框，边缘缩放由窗口管理器提供给无边框窗口的隐形缩放边框完成，无阴影或透明留白；最大化时不显示边框。Wayland 和 Windows/macOS 沿用组件或系统窗口边框。 |

| 浅色/深色主题 | 是 | GPUI Component 主题。 |
| 语法配色主题选择 | 否 | 高亮颜色跟随应用的浅色/深色主题。 |
| 文件夹浏览器 | 是 | 可展开树、隐藏文件设置、点击打开。 |
| 可搜索的语言选择器 | 是 | 引擎已知的全部语言。 |
| 首选项 | 是 | 主题、界面语言、字体、制表符宽度、空格、自动换行、行号、括号、去尾空白、会话、隐藏文件。 |
| 关于 / 键盘快捷键 | 是 | |
| 界面本地化 | 是 | English / 简体中文；启动时自动跟随操作系统语言，可在首选项中覆盖。文档文本、文件名和 CJK 内容完全支持 Unicode。 |
| 命令面板 | 否 | |

## 平台支持

| 平台 | 状态 |
| --- | --- |
| Linux X11 | 是（已在 Xvfb + WGPU/Vulkan lavapipe 上测试）。 |
| Linux Wayland | 已启用构建；由 GPUI 平台层支持。 |
| Windows 10/11 | 已启用构建，使用 GPUI 的 Win32/DirectWrite 后端；CI 构建目标。 |
| macOS 11+ | 已启用构建，使用 Metal/DirectWrite 文本；CI 构建目标。 |

## 0.1 版本有意排除的 Notepad++ 功能

- 插件 API 与插件管理器
- 宏录制
- 打印与打印预览
- 文档地图、函数列表、简单树之外的文件夹工作区
- 用户自定义语言 / Lexilla 词法分析器
- 便携模式打包（可通过 `LUBAN_NOTEPAD_CONFIG_DIR` 重定向配置）
- 原生文件对话框（为保证一致性和可移植性，使用内置对话框）
