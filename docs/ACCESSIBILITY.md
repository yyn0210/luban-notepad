# 无障碍审计（0.16）

本文件记录 0.16 新增界面的无障碍范围、验证方式和已知限制。审计以键盘可达性、
可读标签/角色和状态栏反馈为主，不包含平台读屏器的逐项人工认证。

## 覆盖范围

| 界面 | 角色与标签 | 键盘操作 | 验证 |
| --- | --- | --- | --- |
| 文件树 | 容器 `Tree`，目录 `TreeItem`，文件 `ListItem`；行标签为文件名，选中状态通过 `aria_selected` 暴露 | 树获得焦点后 `↑/↓` 移动选择，`Enter` 打开文件/展开目录，`←` 折叠或回到父目录，`→` 展开，`F2` 重命名，`Delete` 删除，`Ctrl+N` 新建文件 | 单元测试覆盖可见行/选择/路径同步；Xvfb + xdotool 手工验证焦点和按键 |
| 符号大纲 | 容器 `List`，行 `ListItem`；标签为符号名称，行内显示种类和缩进 | 点击后焦点进入大纲；`↑/↓` 移动选中符号，`Enter` 跳转，`←/→` 折叠/展开有子项的符号 | 单元测试覆盖层级/折叠/刷新；Xvfb 手工验证键盘焦点 |
| 快速打开 / Goto Anything | 命令面板搜索框带占位提示，条目有可读标签；结果数量变化通过命令面板重绘更新 | `↑/↓` 选择，`Enter` 确认，`Esc` 关闭；文本编辑键保留给查询框 | 单元测试覆盖查询解析/排序；手工验证 |
| 设置搜索 | 搜索框有占位提示“搜索设置…”，过滤结果按设置组标题组织；无匹配显示空状态 | 输入关键字即可过滤；`Tab` 进入后续控件；关闭首选项清空搜索 | 单元测试覆盖中英文关键字/全部词匹配 |

## 焦点与错误反馈

- 新增交互控件使用 GPUI 默认的悬停/按下视觉状态；文件树和编辑组点击后获得
  焦点，方向键立即作用于该区域。
- 所有错误通过状态栏文本暴露；设置导入/导出、文件操作、搜索非法 glob 和
  替换预览失败都会写入状态栏，并在相关对话框中保留错误。
- 禁用态：没有历史时“后退/前进”命令禁用；没有工作区时“工作区搜索”复选框
  禁用；没有可撤销替换时“撤销替换”禁用；分屏不存在时“取消分屏”不改变状态。

## 已知限制

1. **括号配色不解析字符串/注释**：括号扫描只按字符配对，字符串或注释中的
   括号也参与嵌套深度；未配对括号不着色。普通文本超过 2 MB 时不启用。
2. **符号大纲是正则启发式**：多行声明、宏生成代码、动态语言元编程和复杂
   缩进结构可能漏报或层级不准；不支持的语言显示空状态。
3. **文档地图为采样近似**：最多采样 4,000 行并按 160 个视觉行分箱；超长行
   只按相对宽度显示，不能精确到字符列。大文件/磁盘引擎只显示视口比例。
4. **标尺为像素近似**：按字号估算等宽字符宽度，非等宽字体或复杂字形下
   列位置会有偏差。
5. **快捷打开最多 50 条**，工作区索引单根最多 200,000 个文件；截断后仍可
   使用已收集部分，但更深的文件不会出现在结果中。
6. **阅读器兼容性**：GPUI 的 AccessKit 树由各控件角色组成；本版本未对
   NVDA/VoiceOver/Orca 做逐项人工认证，复杂浮层的读屏顺序可能因平台而异。
7. **文档地图和面包屑**：视图菜单可隐藏；隐藏状态保存在全局设置中，工作区
   文件不覆盖这两个字段。
